# PulseFit Pro · Frontend

Aplicación Angular 22 del panel del entrenador y la app del cliente.

```bash
npm install
npm start        # servidor de desarrollo en http://localhost:4200
npm run build    # compilación de producción en dist/
npm test         # tests unitarios (Vitest)
```

Explicación de la estructura y de cada pieza: [../docs/GUIA-ANGULAR.md](../docs/GUIA-ANGULAR.md).
